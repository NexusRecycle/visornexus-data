# Fuentes de Informacion

## RETC/SINADER

Fuente principal para datos de generadores, receptores, residuos declarados y trazabilidad.

- Sitio: https://retc.mma.gob.cl/
- Institucion: Ministerio del Medio Ambiente, Chile.

## IDE Chile

Fuente prevista para capas territoriales oficiales y cartografia base.

- Sitio: https://www.ide.cl/

## Capas urbanas complementarias

El plugin VisorNexus utiliza tambien capas complementarias para analisis urbano, como censo/manzanas, puntos verdes, puntos limpios, areas verdes, ejes viales y paraderos.

Cada capa incorporada debe registrar:

- Fuente original.
- Fecha de descarga.
- Sistema de coordenadas.
- Campos usados por el plugin.
- Transformaciones aplicadas.
